# Base64 Tool

一个简单的 Base64 编码/解码网页工具，可直接在浏览器中使用。

## 功能

- 文本转 Base64
- Base64 转文本
- 纯前端实现
- 数据不出本地


## 说明

1. 该项目适合部署在 GitHub Pages 上，上传后可直接访问。
2. 使用常见的 UTF-8 编码


## 使用

在线访问：  
https://0hyd.github.io/base64-tool

本地运行：  
下载发行版安装包，用浏览器打开 `index.html` 即可。
